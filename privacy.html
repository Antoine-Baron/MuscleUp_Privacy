Privacy Policy

This Privacy Policy describes how the mobile application MuscleUP ("the Application") handles user data.

1. Data Collection

The Application does not collect, store, or process any personal data.

No information such as:

  • Name
  • Email address
  • Location data
  • Device identifiers
  • Health or fitness data linked to an identity

is collected or transmitted.

2. Local Data Storage

The Application allows users to record workout-related information (e.g., exercises, weights, repetitions).

All such data is stored locally on the user’s device only using a SQLite database.

This data:

  • remains on the device
  • is not transmitted to any server
  • is not accessible by the developer

3. No Data Sharing

The Application does not share any data with third parties.

4. No Third-Party Services

The Application does not use any third-party services that collect data, including:

  • Analytics tools
  • Advertising networks
  • Cloud storage services

5. Data Security

Since all data is stored locally, the security of the data depends on the user's device security (e.g., passcode, biometric lock).

The developer does not have access to user data and cannot recover lost data.

6. Data Retention

Data is retained on the device until the user deletes it.

Users can delete their data by:

  • clearing the application data
  • or uninstalling the Application

7. Children’s Privacy

The Application does not knowingly collect any data from children under the age of 13.

Since no data is collected, no specific processing of children's data occurs.

8. Changes to This Policy

This Privacy Policy may be updated from time to time.

Users are encouraged to review this page periodically.
