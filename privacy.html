01

Data Collection

The developer does not collect, receive, or process any personal data. Nothing you enter in the Application is sent to the developer or to any server.

No information such as:

  • Name or username
  • Email address
  • Location data
  • Device identifiers
  • Health, fitness or body measurement data

is collected by the developer or transmitted off your device.

02

Data Stored on Your Device

The Application lets users create an account and record information about their training and their body. This information may include:

  • Account A username and a password. The password is hashed and never stored in plain text. If you choose to stay signed in, the session is also kept on the device.
  • Profile e.g., name, height, weight, age, training level and goal.
  • Workouts e.g., sessions, exercises, sets, repetitions and weights.
  • Body measurements e.g., weight history, body composition and hydration level.
  • Preferences e.g., the display theme.

All such data is stored locally on the user’s device only using a SQLite database.

This data:

  • remains on the device
  • is not transmitted to any server
  • is not accessible by the developer
03

No Data Sharing

The Application does not share any data with third parties.

Since the developer never receives user data, it cannot be sold, rented or disclosed.

04

No Third-Party Services

The Application does not use any third-party services that collect data, including:

  • Analytics tools
  • Advertising networks
  • Cloud storage services
05

Data Security

Since all data is stored locally, the security of the data depends on the user's device security (e.g., passcode, biometric lock). This matters all the more for body measurements, which are health-related data.

Passwords are hashed before being stored: they are never kept in plain text.

The developer has no access to user accounts or data, and therefore cannot reset a forgotten password or recover lost data.

06

Retention, Export & Deletion

Data is retained on the device until the user deletes it.

Users can:

  • export their data from Profil › Données
  • delete their data from Profil › Données
  • clear the application data
  • or uninstall the Application

An exported file is saved or shared wherever the user chooses. From then on, it is under the user’s control and no longer stays only inside the Application.

07

Children’s Privacy

The Application does not knowingly collect any data from children under the age of 13.

Since no data is transmitted to the developer, no processing of children's data by the developer occurs.
